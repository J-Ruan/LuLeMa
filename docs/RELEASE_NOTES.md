# 撸了吗 v0.2.0

- 五个底部入口：新增独立成就中心，17 枚独立图形勋章；保留已有解锁状态，支持历史补录与导入后的检查。
- 新增手部运动次数、出货量（mL）和手填地点，支持保存、编辑、详情、统计与备份。
- 新增单次时长娱乐点评，不作健康或个人能力评分。
- 首页可切换周报、月报、年报，提供本地趋势、有效时长平均值、新字段合计、地点摘要与新勋章。
- 记录数量统一使用“次”；修复未填时长统计、无关设置重排提醒、异常时间戳与错误提示。
- Room v1→v2 显式无损迁移；默认密码保护的备份升级为格式 v2，仍可导入 v1。

Android 8.0+，包名 `com.lulema.app`，版本 `0.2.0` / `2`。全部记录本地保存，无账号、网络或定位权限，无广告和追踪。

升级前请主动导出并验证备份。正式签名与旧 Debug 签名不同，首次切换通常需要先备份、卸载旧版、安装再恢复。格式 v2 备份不能导入 v0.1.0，加密密码无法找回。提醒可能受系统省电策略延迟。

只有实际通过签名检查及安装冒烟的正式签名 APK 才可附于稳定版；校验下载附件的 SHA256SUMS。
