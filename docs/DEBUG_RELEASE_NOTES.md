# 撸了吗 v0.2.0 · Debug 测试版

这是可安装的 **Debug 预发布包**，使用 Android 开发签名，**不是正式签名的稳定版本**。

下载下方 `LuLeMa-v0.2.0-debug.apk`，支持 Android 8.0 及以上。`SHA256SUMS` 用于校验本次发布的 APK。

## 包含功能

- 新增选填的手部运动次数、出货量（mL）、手填地点，完整接入记录、详情、编辑、备份与报告。
- 五栏导航与独立成就中心，保留九枚旧勋章，新增八枚；历史补录与导入会检查，删除不撤销解锁。
- 单次时长娱乐点评，以及首页可切换的本地周报、月报、年报。
- 记录单位统一“次”；平均时长 / 趋势忽略未填值；无关设置不再重排提醒；异常未来时间戳校验。
- Room v1→v2 显式迁移，默认密码保护的格式 v2 备份，兼容导入旧 v1；保留月历、彩蛋、深色模式和低频提醒。
- 无需登录，不申请 INTERNET 权限，无广告与追踪。

## 验证与限制

发布前必须通过单元测试、Android Lint、Debug 签名检查以及 API 30 模拟器上的 Room / Compose 设备测试。

Android 13+ 通知授权、不同厂商的省电策略与文件提供器仍需真机回归。本工具不提供医学诊断。

**安装 / 升级前请主动备份。** 不同 Debug 构建的签名密钥可能不同；若无法覆盖安装，请先导出数据，再卸载旧版、安装并恢复备份。加密备份密码无法找回。

**正式稳定版仍需维护者配置四项签名 Secrets，并通过正式签名候选包验证。此包不会代替正式 Keystore。**
