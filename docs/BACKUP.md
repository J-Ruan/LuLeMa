# 备份与隐私

应用没有 INTERNET 权限，无账户、服务器、广告或追踪。数据保存在应用私有目录的 Room 数据库。系统云备份及设备迁移均排除敏感数据。数据库本身不额外加密，依赖 Android 应用沙箱和设备存储加密；已解锁、Root 或被攻破的设备不在保护边界内。

## 导出

我的 → 导出备份 → 默认密码保护 → 至少 8 位密码 → 通过系统文件选择器选择保存位置。

密码无法找回。保存到云盘提供器是用户主动选择的行为，App 不会自行上传。导出后应确认文件可读，妥善保管密码，并在清除或卸载前确认能导入。取消密码保护会显示明文隐私警告；明文 JSON 包含全部记录、必要设置与成就。

v0.2.0 新导出使用格式 v2，包括 `formatVersion`、`exportedAt`、`records`、`settings`。每条记录新增可空的 `handCount`（非负整数）、`volumeMl`（0–1000 mL，最多三位小数）和 `location`（手填，最多 100 字）。留空为 null，填写 0 会保留 0；旧版时长的 0 继续表示未填写。备份包含这些私密字段、心情、备注和全部勋章，请妥善保管。

继续支持导入格式 v1 的明文和加密文件，缺少三个新字段时恢复为 null。v0.1.0 无法导入格式 v2，请保留升级前的备份。加密外层版本保持 1，包括 `encryptedVersion`、`salt`、`iv`、`ciphertext`（Base64），加密算法和 AAD 保持兼容。

- PBKDF2-HMAC-SHA256，210,000 次迭代，256 位密钥，随机 16 字节 salt。
- AES-256-GCM，随机 12 字节 IV、128 位认证标签，AAD `LuLeMa/backup/1`。
- 每次导出随机化。校验失败或密码错误会拒绝解密，不写入数据库。
- 文件读取上限 16 MiB；明文导出编码上限 8 MiB；导出超过上限会提示失败。
- 至多 50,000 条记录，JSON 嵌套至多 24 层；未知字段、成就 key 或格式版本拒绝导入。成就允许原九枚及新增八枚的稳定 key。
- 创建时间、修改时间、解锁时间和导出时间均检查正数及合理上限：最多允许本机时间五分钟的偏差，修改时间不得早于创建时间。极端未来时间戳拒绝导入；请先检查设备时钟，不会静默改写备份。

## 导入

我的 → 导入备份 → 输入密码（明文留空） → 选择文件 → 预览 → 选择合并或覆盖。

合并按 UUID 识别记录，同 UUID 仅接受 `modified` 较新的版本，相同时保留本机。合并保留本机设置与成就，并根据最终记录检查尚未解锁的历史成就；不会根据日期去重，因此同日多条记录不会丢失。

覆盖在单个 Room 事务中替换全部记录、设置和成就，保留备份中的解锁时间，再根据导入记录补算尚未解锁的成就。提醒强制关闭，用户检查设置后自行启用。格式验证在写入之前完成，事务失败回滚。文件本身包含重复 UUID 时拒绝导入，避免歧义。错误密码、篡改或预览失败均不会改动数据库。

地点仅显示在本地详情和报告，不进入通知标题、锁屏或应用日志。App 不申请 INTERNET 或定位权限；自行选择云盘文件提供器时，其上传行为由提供器负责。数据库自身仍依赖 Android 沙箱和设备加密，备份加密不等于数据库加密。

清除全部数据需要二次确认，并清除记录、设置、成就及提醒。它不删除已由用户导出的文件、系统文件提供器的副本或磁盘硬件残留；导出文件请自行管理。
